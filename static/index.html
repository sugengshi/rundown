Worth knowing before you rely on it

  • Viewer links are public. Anyone who has one can read the running order. Notes stay hidden from viewers unless you turn sharing on.
  • Nothing deletes itself. Archiving is manual and reversible. Permanent deletion is manual and is not.
  • Countdowns run on each viewer's device from a synced start time, so they stay smooth on bad wifi — but a disconnected viewer will keep counting the wrong segment without saying so.
